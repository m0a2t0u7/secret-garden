# ひみつの植物園

課金なしの植物学習ゲーム。スマートフォンとPC向けの静的Webアプリです。

## 遊び方
- はじめに種500個をプレゼント。毎日のプレゼントは200個。
- 10連ガチャは種200個。かぶった植物は種10個に変換。
- 植物を観察して初回20個の種を獲得。
- クイズの解説を読んで初回30個、復習は20個を獲得。間違えても学べます。
- 種20個で植物ガチャ。6種類は各1/6の確率。同じ植物は種10個に変換。
- 集めた植物を温室に飾れます。未発見の植物も図鑑で学べます。
- 進み具合はブラウザのlocalStorageに自動保存。ガチャの消費と結果は同時保存。
- 設定からJSONバックアップを書き出し・読み込み可能。別のURLや端末への移行に使えます。

## ローカルで遊ぶ
Python 3がある場合、このフォルダで `python3 -m http.server 8000` を実行し、ブラウザで `http://localhost:8000` を開きます。
`index.html` を直接開く方法もありますが、ブラウザによって保存の挙動が異なるためHTTPを推奨します。

## GitHub Pagesで公開
1. GitHubで空のリポジトリを作成。
2. このフォルダの内容をリポジトリのルートへアップロード。
3. Settings → Pages → Build and deployment → Sourceを「Deploy from a branch」に設定。
4. Branchをmain、フォルダを / (root) にしてSave。
5. 表示された公開URLを開く。

外部API、サーバー、ビルド、課金設定は不要です。相対パスなのでプロジェクトのGitHub Pagesにも対応しています。

## 内容と制限
収録植物：イチゴ、ヒマワリ、アジサイ、チューリップ、ミント、アサガオ。
イラストはAIで生成した学習用の描画で、植物の識別や食用判断には使わないでください。品種によって形や開花時期は異なります。
自動保存は端末とブラウザごとです。クラウド同期はありません。ブラウザの保存領域が使えない場合は進行を確定せず通知します。
植物園は収集した植物を一覧表示し、選んだ植物を観察カードに飾る構成です。温室背景はイラストで、自由配置の機能はありません。
